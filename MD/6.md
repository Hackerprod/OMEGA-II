2. AMB-54 — ACEPTAR

Gobierna el hecho de si correctness fue realmente adjudicado, no la mera existencia de un terminal de mayor prioridad.

Mapeo:

correctness_adjudicated = FAIL
→ kernel_status = NOT_QUALIFIED
→ kernel_correctness = FAIL
→ kernel_rebuild_required = true

Esto se conserva incluso si el terminal principal es, por ejemplo:

MEASUREMENT_STACK_INVALID

porque el terminal y el estado independiente del kernel son dimensiones distintas.

terminal previo de mayor prioridad
→ kernel_status = NOT_EVALUATED

sólo cuando ese terminal impidió producir una adjudicación válida de correctness.

Caso explícito:

KERNEL_CORRECTNESS_PASSED_STEP8_NOT_EVALUATED
→ kernel_status = NOT_EVALUATED
→ kernel_correctness = PASS
→ kernel_rebuild_required = NOT_EVALUATED

55d — kernel sin encoder propio

No debe contar como fallo.

entonces los fixtures:
