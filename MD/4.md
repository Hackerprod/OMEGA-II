OMEGA MD/408 — T0.0 Final Ambiguity Closure
I. Definiciones
BW_med(W)
= mediana del ancho de banda de las 31 repeticiones válidas
  en working set W.

BW_base
= ancho de banda de referencia de la meseta de la curva.

degradation(W)
= 1 - BW_med(W)/BW_base.

R_L2(W)
= bytes que abandonan L2 hacia la jerarquía compartida
  / B_logical.

R_DRAM(W)
= corrected_DRAM_bytes / B_logical.

CounterMove(R_test,R_base)
= R_test >= 0.50
  AND R_test-R_base >= 0.25
  AND [R_base=0 OR R_test/R_base >=1.50].

q95_AA
= percentil 95 tipo-7 del ruido A/A.

delta_perf
= max(0.10, 2*q95_AA).

C_L2
= capacidad L2 útil efectiva congelada.

C_LLC
= capacidad compartida útil efectiva congelada.

B_core_actual
= bytes persistentes reales del núcleo, incluido
  padding/alineamiento/metadata necesaria por el kernel.
II. DECISIONES
1. AMB-39 — ACEPTAR CON UNA PRECISIÓN
39a — degradación

ACEPTAR.

degradation(W) = 1 - BW_med(W)/BW_base

es la métrica gobernante.

L(W) queda descriptiva/informativa.

39b — baseline de contador

ACEPTAR para L2.

R_base,L2
= mediana de R_L2(W)
  para los puntos válidos W∈[64 KiB,512 KiB].

Requerir al menos tres puntos válidos; de lo contrario:

MEASUREMENT_STACK_INVALID
subcause=L2_BASELINE_NOT_ESTABLISHED

MODIFICAR ligeramente para LLC.

Sea:

W0 = primer punto válido con W_worker >= 1.25*C_L2.
R_first = R_DRAM(W0).

La baseline LLC debe construirse con los tres primeros puntos válidos consecutivos, comenzando en W0, que no satisfagan:

CounterMove(R_i,R_first).

No está permitido saltar un punto que ya mostró CounterMove para buscar tres puntos posteriores más cómodos.

Si antes de obtener tres puntos consecutivos aparece CounterMove:

MEASUREMENT_STACK_INVALID
subcause=LLC_BASELINE_NOT_ESTABLISHED

Una vez obtenidos esos tres:

BW_base,LLC = mediana de sus BW_med
R_base,LLC  = mediana de sus R_DRAM.
39c — corrección del tráfico DRAM

MODIFICAR.

Usar la ventana idle pre-bloque ya calificada por P-02:

idle_DRAM_rate
= mediana de la tasa DRAM durante esa ventana.

corrected_DRAM_bytes
= max(
    0,
    raw_DRAM_bytes
    - idle_DRAM_rate * measured_region_seconds
  ).

La ventana post-bloque se conserva para detección de contaminación/deriva, pero no cambia retrospectivamente el baseline de corrección.

Así no se escoge un baseline después de observar el resultado.

39d — ruido global

ACEPTAR.

q95_AA_global
= max(q95_AA de todas las celdas A/A calificadas).

delta_perf
= max(0.10,2*q95_AA_global).

Como PASS_QUALIFIED ya exige q95_AA_global<=0.05, en un stack válido el piso material queda en 10%.

39e — rejilla completa

ACEPTAR.

No terminación anticipada. Recorrer la rejilla congelada completa.

AMB-39 = CLOSED.

Los casos STRESS_NUMERIC pasan si:

III. RACIONAL
R1. Baseline LLC

No se puede permitir que el algoritmo ignore el primer punto donde aparece una transición real y luego construya una “meseta” con puntos posteriores. Exigir tres puntos consecutivos evita seleccionar retrospectivamente una baseline favorable.

R2. Corrección DRAM

El idle usado para corregir bytes debe existir antes del resultado. La ventana posterior sigue siendo extremadamente útil para detectar contaminación, pero usarla para redefinir el baseline permitiría que el resultado afectara su propia corrección.

R3. Stress numeric

En casos extremos, el error absoluto deja de tener una escala universal útil. nRMS es la medida adecuada, siempre que la referencia misma permanezca finita.

R4. Identidad CPU

family/model/topology son mejores identificadores técnicos que un brand string textual susceptible a diferencias cosméticas.

R5. Inputs

El JUEZ es responsable de la cadena de custodia y freeze, no de tener que escribir personalmente cada implementación independiente. Mezclar esas funciones reduciría, no aumentaría, la independencia.
