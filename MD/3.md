0. Definiciones normativas
B_logical
= bytes lógicos conocidos que el benchmark exige leer
  durante una repetición.

R_DRAM
= corrected_DRAM_bytes / B_logical.

R_L2
= bytes que abandonan L2 hacia la jerarquía compartida
  / B_logical.
  Se derivan de un contador de L2 miss/fill/request
  validado; si el contador cuenta líneas, bytes=líneas×64.

q95_AA
= percentil 95, Hyndman-Fan tipo 7,
  del ruido relativo A/A.

delta_perf
= max(0.10, 2*q95_AA).

CounterMove(R_test,R_base)
= R_test >= 0.50
  AND R_test-R_base >= 0.25
  AND, cuando R_base>0,
      R_test/R_base >= 1.50.

B_core_payload
= 2,359,296 bytes.
  Payload contractual Q4 del núcleo d512.

B_core_actual
= bytes persistentes realmente asignados al kernel,
  incluyendo padding/alineamiento requerido.

= {1,2,4,8,16,32}.
