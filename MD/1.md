0. Definiciones
d       = ancho contractual del núcleo = 512
P       = 16 d² = 4,194,304 pesos únicos del núcleo
q_eff   = bytes persistentes efectivos por peso Q4, incluidas escalas
B_core  = P × q_eff = bytes persistentes del núcleo Q4

K       = número de aplicaciones recurrentes del mismo núcleo
m       = número de filas/slots procesados conjuntamente

c_X(K,m) = tiempo/ciclos de la variante X
            X∈{A residente, B untied, C expulsada}

rho(K,m) = c_A(K,m) / c_B(K,m)
           menor es mejor para residencia

eta(m)   = throughput efectivo del kernel a workspace m
           bajo el estimando que congele T0

C_L2     = capacidad L2 útil medida por dominio de ejecución
C_LLC    = capacidad LLC útil medida, no tamaño nominal de marketing

Los valores físicos reportados para el i7 siguen siendo TBD-VERIFY hasta T0.0.

2. Ambigüedades bloqueantes de T0
A-03 — workers CPU híbrida

DECISIÓN: 8 P-cores como plataforma primaria.

Primary:
8 P-cores
1 worker por P-core físico
SMT OFF
E-cores excluidos

Los 4 P-cores se mantienen como caracterización secundaria obligatoria para estudiar ocupación por shard y escalado, pero no gobiernan PASS/FAIL.

8P+8E no entra en H0/H1 primario.

Racional: el mecanismo depende de shards fijados a cachés privadas. Los ocho P-cores son el dominio homogéneo completo de la plataforma objetivo. Mezclar E-cores introduciría otra topología L2 antes de demostrar el mecanismo básico.

A-04 — rho y K=8 dentro de LLC

DECISIÓN: conservar los umbrales de rho, eliminar K=8 como condición implícita.

rho <= 0.50  = PASS mínimo
rho <= 0.25  = señal fuerte

Pero sólo pueden adjudicarse cuando:

A está físicamente residente
B está físicamente no-residente

según las mediciones de T0.0/H0.

Definimos:

K_NR = menor K del barrido para el cual
       B queda demostrado como no-residente.

K_NR no se deduce de “30 MiB nominales”. Se determina tras medir C_LLC y tráfico real.

El barrido incluirá K=16. Si K=8 resulta todavía residente en LLC, su rho es descriptivo y no adjudica el gate.

C sigue siendo el control positivo de expulsión.

A-05 — combinación de criterios

DECISIÓN: conjunción.

H0 tiene tres condiciones obligatorias:

H0-R = residencia
H0-M = matrixización
H0-K = rodilla física/cache causal
H0 PASS = H0-R AND H0-M AND H0-K

SMT es caracterización y no gate.

H0-R

En m=1, para K=K_NR:

rho(K_NR,1) <= 0.50

y las mediciones de memoria deben demostrar el estado residente/no-residente esperado.

H0-M

Definimos:

m* = menor m de {8,16}
     tal que eta(m)/eta(1) >= 1.50

Si ninguno cumple:

H0-M FAIL

>=2.0 es señal fuerte, no requisito.

H0-K

Debe aparecer una transición coherente al cruzar la capacidad L2 útil medida. La variable de barrido será bytes por dominio L2, no d.

H1

H1 usa el bloque recurrente realista y debe demostrar nuevamente:

rho(K_NR,m*) <= 0.50

más que m* conserva la ventaja de matrixización.

Por tanto, una ventaja existente únicamente en m=1 no sostiene H1.

Barridos

Barrido 1 permanece, adaptado:

K ∈ {4,8,16}
m ∈ {1,2,4,8,16,32}

Barrido 2 de FLOPs constantes permanece como caracterización:

K*m ∈ {32,64,96}

K=32 aquí es hardware characterization, no modelo científico entrenado.

A-02 — d alternativos y rodillas

DECISIÓN: gate científico exclusivamente d=512.

d != 512
→ ENGINEERING_SMOKE_ONLY
→ EVIDENTIARY_WEIGHT=ZERO

Por tanto se elimina del gate la serie:

d={384,640,768,1024}

La rodilla se busca manteniendo d=512 y variando el working set físico.

Definimos:

r_L2 = bytes Q4 activos por P-core / C_L2

y se caracteriza aproximadamente:

r_L2 ∈ {0.25,0.50,0.75,1.00,1.25,2.00}

mediante bancos/copias/padding del mismo kernel d512.

Así se mide caché sin convertir otros d en evidencia arquitectónica.

A-18 — AVX-512

DECISIÓN: sustituir por:

1. referencia escalar / PyTorch → correctness
2. AVX2                    → baseline nativo
3. AVX-VNNI 256-bit        → ruta optimizada

La tercera sólo existe si T0.0 confirma soporte mediante CPUID.

No hay ruta AVX-512 en el gate del i7-13700F.

A-19 — qué m gobierna

DECISIÓN: separar aislamiento físico y régimen útil.

H0 residencia pura: m=1
H0 matrixización:   m* elegido de {8,16}
H1 definitivo:      m=m*

m=4 se reporta como punto intermedio.

Por tanto:

rho(m=1) PASS por sí solo
≠
tesis OMEGA PASS

H1 debe conservar la ventaja en m*.

A-20 — E-cores

DECISIÓN: fuera del gate primario.

Los E-cores pueden caracterizarse después de H0/H1 P-core.

Cuando se estudien, la unidad física será:

cluster de 4 E-cores
→ una L2 compartida de cluster

No se fingirá que cada E-core tiene una L2 privada independiente.

Ningún resultado E-core puede rescatar un FAIL del gate 8P.
