4. AMB-01 / AMB-02 — Q4 y equivalencia
Formato Q4 normativo

Se escribe antes de medir, como contrato independiente del kernel:

G = 32 pesos
scale = max(abs(w_group)) / 7
scale almacenada como IEEE FP16 little-endian
sin zero-point

q = round-to-nearest-even(w / scale)
q = clamp(q,-7,+7)

si max_abs=0:
    scale=0
    todos q=0

nibble = q & 0xF
índice par  -> nibble bajo
índice impar -> nibble alto

16 bytes payload + 2 bytes scale
= 18 bytes / 32 pesos

Por tanto:

q_eff = 18/32 = 0.5625 B/peso
B_core = 2,359,296 bytes

El kernel retenido no define este formato; debe ajustarse a él.

Referencias

Tres niveles:

1. especificación matemática Q4 congelada
2. encoder/decoder escalar independiente
3. PyTorch CPU float64 para referencia numérica final
Correctness

Exigir:

payload Q4                = bit-exact
FP16 scales               = bit-exact
acumulador entero,
cuando exista observable   = exacto

Salida flotante:

max_abs_error <= 2e-4

nRMS =
RMS(y_kernel-y_ref) / max(RMS(y_ref),1e-12)
<= 1e-4

Son nuevos criterios prospectivos; no heredan un PASS de Legacy.

B. RACIONAL CIENTÍFICO
K_NR pertenece al experimento que contiene B

La capacidad medida permite diseñar el barrido, pero no demuestra que la implementación untied real esté fuera de caché. Declarar K_NR en T0.0 únicamente por K×B_core > C_LLC volvería a cometer el error de confundir capacidad nominal/estimada con residencia física.

La instrumentación debe observar el fenómeno causal

El objetivo T0 no es demostrar sólo que “un array grande tarda más”. Se intenta atribuir la diferencia a tráfico de memoria. Por eso QPC sin una ruta DRAM válida no basta para PASS_QUALIFIED.

C_LLC es efectivo, no algebraico

La jerarquía real puede ser no inclusiva, compartida y afectada por shards, código, buffers y otros datos. El número que necesita H0 es la rodilla observada bajo el patrón real de workers, no 24+30 MiB reinterpretado como una caché monolítica.

d512 permanece absoluto

T0 puede variar bytes físicos, copias, bancos y presión de caché sin convertir d384/d640/etc. en “modelos de prueba”. Eso mantiene el contrato d512 y permite caracterizar el hardware.

Q4 debe existir antes que el kernel

Si el retained kernel define retroactivamente qué significa Q4, una implementación equivocada podría validarse contra sí misma. Congelar el formato matemático primero evita esa circularidad.
