1. Definiciones
D_read(r)
= BW_Q4_logical_8P(r) / BW_DRAM_read_8P.

D_read_gate
= max_r D_read(r) >= 1.00.

P_Q4_i(r,m)
= throughput Q4 del core físico i,
  ruta ISA r y matrixización m.

P_instr_i(r)
= techo de instrucción medido por core físico i y ruta r.

P_ref
= P-core de referencia usado para el barrido completo de m.

T0_0_COMPLETE
= T0.0 ha cerrado todas sus mediciones y campos requeridos,
  sin TBD científico pendiente dentro de su alcance.

EFFECTIVE_FREQUENCY
= frecuencia efectiva obtenida de una fuente hardware/documentada,
  no inferida a partir de throughput.

Orden de preferencia:

1. APERF/MPERF si SEP/VTune la expone inequívocamente;

2. CPU_CLK_UNHALTED + referencia temporal documentada
   si la herramienta proporciona la conversión válida;

3. métrica equivalente explícitamente documentada por VTune.

Medir únicamente:

P_ref bajo carga P_instr
y
un E-core representativo bajo carga P_instr.

Registrar:

source/event/formula

y continuar.

inferir GHz desde P_instr;
usar PDH 2100 MHz;
usar una cadena de sumas dependientes como reloj.
