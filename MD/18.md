III. HID DESPUÉS DE UN FAIL PREVIO
3. Interpretación (2a) — CONFIRMADA

Si dentro de un OFFICIAL_RUN:

1. correctness produjo previamente un FAIL válido;

2. posteriormente, dentro de la misma corrida,
   el harness detecta HID en otra llamada/fixture;

entonces la corrida ya no puede convertir aquel FAIL en una conclusión oficial sobre el KUT.

Salvo R1/R2 de mayor prioridad:

terminal = AB
subcause = HARNESS_INPUT_DEFECT

Los campos finales gobernantes son:

kernel_status           = NOT_EVALUATED
kernel_correctness      = NOT_EVALUATED
kernel_rebuild_required = NOT_EVALUATED

y:

RETAINED_KERNEL_NOT_QUALIFIED

NO puede declararse desde esa corrida.

3.1 Preservación factual

Si el FAIL anterior había sido completado válidamente antes de HID, sus datos crudos no se destruyen.

Puede preservarse factual y auditivamente:

correctness_result_raw = resultado existente
correctness_adjudicated = FAIL

pero, debido a HID posterior:

correctness_evidentiary_status = NOT_APPLICABLE

para la adjudicación final de esa corrida.

Es decir:

correctness_adjudicated
= hecho histórico de lo que produjo la rutina

kernel_status
= conclusión oficial permitida al cierre del run

La corrida debe repetirse con:

nuevo run_id
inputs corregidos

si se desea una adjudicación oficial del kernel.

IV. HID ANTES DE 5.4
4. Interpretación (2b) — CONFIRMADA

La regla de MD/421 §I se aplica a cualquier defecto contractual equivalente descubierto después de creado el run_id, no sólo durante 5.4.

Por tanto un HID detectado durante 5.1–5.3 establece, salvo terminal superior:

ABORTED_NO_VERDICT
subcause = HARNESS_INPUT_DEFECT

Si 5.4 todavía no comenzó:

official_correctness_5_4 = NOT_EXECUTED
correctness_result_raw    = NONE
correctness_adjudicated   = NOT_ADJUDICATED

kernel_status             = NOT_EVALUATED
kernel_correctness        = NOT_EVALUATED
kernel_rebuild_required   = NOT_EVALUATED

La precedencia continúa siendo:

R1 > R2 > AB

según el ranking congelado.

Estas dos interpretaciones son derivaciones de las reglas ya presentes en REV25 y no requieren REV26.
