IV. ACTIVATION_RANGE_ERROR
4. Confirmación — interfaz concreta es implementación

Confirmo.

La representación concreta puede ser, por ejemplo:

enum
status code
return object
excepción interna capturada por el harness

y no forma parte del contrato matemático.

El criterio normativo es únicamente que la ruta aplicable:

1. identifique inequívocamente la clase
   ACTIVATION_RANGE_ERROR;

2. lo haga para el fixture correcto;

3. no emita output parcial presentado como válido;

4. produzca un resultado que el harness pueda registrar
   determinísticamente como esa clase normativa.

La interfaz concreta debe documentarse en el manifest/harness, pero no requiere una nueva decisión científica.
