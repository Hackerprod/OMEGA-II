OMEGA MD/409 — T0.0 Final Mechanical Ambiguity Closure
Definiciones
BW_med(W)
= mediana del ancho de banda de las repeticiones válidas
  del punto con working set W.

BW_base
= ancho de banda de referencia contra el cual se calcula
  degradation.

idle_DRAM_rate
= tasa de tráfico DRAM durante la ventana idle pre-bloque
  que efectivamente calificó.

B_core_actual
= bytes persistentes realmente necesarios por el kernel:
  payload + padding + alignment + metadata persistente.

No incluye activaciones, buffers temporales, scratch transitorio
ni memoria de instrumentación.
1. AMB-49 — ACEPTAR

Usar exactamente:

idle_DRAM_rate
= mediana de 60 tasas DRAM de bins consecutivos de 1 s

obtenidas durante el intento de ventana pre-bloque que pasó P-02, mediante la misma ruta DRAM/IMC VALID usada para la región medida.

Si no existen 60 bins válidos o la ruta DRAM deja de ser válida:

MEASUREMENT_STACK_INVALID
subcause=IDLE_DRAM_BASELINE_INVALID

No usar intentos idle fallidos ni la ventana post-bloque para corregir retrospectivamente.

AMB-49 CLOSED.

2. AMB-50 — ACEPTAR

Para L2:

BW_base,L2
= mediana de {
    BW_med(W)
    para cada punto válido
    W ∈ [64 KiB,512 KiB]
  }.

Es decir, mediana de las medianas por punto, no pooling de las 31 repeticiones de todos los puntos.

Esto da el mismo peso a cada punto de la meseta.

AMB-50 CLOSED.

3. AMB-51 — ACEPTAR CON PRECISIÓN DE ESTADO

Antes de crear el run_id oficial, ejecutar un preflight sobre todos los fixtures congelados usando exclusivamente las dos referencias independientes.

Debe verificar:

dominio permitido
rango del encoder
finitud de referencias
clasificación STANDARD vs STRESS_NUMERIC

Si falla:

NO_LAUNCH
run_id no consumido
preflight_status=FIXTURE_SET_INVALID

Se corrigen fixtures/spec mediante nueva revisión; no es un resultado experimental.

Si una condición equivalente aparece inesperadamente después de comenzar el run:

ABORTED_NO_VERDICT

según la precedencia congelada.

Por tanto no existe un ABORTED_NO_VERDICT “local al fixture” que permita continuar silenciosamente el juicio del kernel dentro del mismo run.

AMB-51 CLOSED.
