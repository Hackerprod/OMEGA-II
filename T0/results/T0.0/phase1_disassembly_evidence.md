## FP16 scale conversion

Literal source in `src/q4_kernel.cpp`:

```cpp
__forceinline float half_to_float_fast(std::uint16_t h){
    const __m128i packed=_mm_cvtsi32_si128(static_cast<int>(h));
    return _mm_cvtss_f32(_mm_cvtph_ps(packed));
}
```

The optimized assembly at `phase1_q4_kernel.asm:7494-7498` moves the 16-bit payload to XMM and emits `vcvtph2ps xmm3,xmm0`. This conversion is inlined; no external conversion-helper call appears at the conversion site.
